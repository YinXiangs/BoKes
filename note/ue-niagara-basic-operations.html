三、完整水珠流动 HLSL 源码

// 玻璃雨滴流动HLSL，附带变量注释
float2 uv = UV;
// 竖直向下偏移，模拟水珠往下滑落
uv.y += Time * FlowSpeed;
// 微小随机扰动，水珠不会规整平行流动
uv += RandomValue * Disturb;
float finalColor = Texture2DSample(RainTex,uv);
return finalColor;
