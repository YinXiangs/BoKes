UE5特效学习笔记｜Niagara基本操作

发布日期：2025‑12‑10

本篇梳理 Niagara 粒子系统基本内容，在熟悉UE引擎的基础上步入Niagara特效设计的学习

一、效果预览截图

Niagara粒子系统打破了旧系统Cascade的限制，让美术师能全权掌控效果逻辑，可以通过组合“模块”像搭积木一样定义粒子行为，甚至用HLSL编写代码创造独一无二的模块。同时也打破了数据孤岛，粒子可与场景、蓝图、外部数据实时交互，让特效真正“活”起来。

二、UE4 与 UE5 HLSL 语法差异对照表

板块 具备内容
发射器更新 Spawn Rate，Spawn Bust Instantaneous
粒子生成 Shape Location，Add Velocity，Intial Mash Orientation，Sprite Facing and Alignment
粒子更新 Size，Kill，Force，Color，Point，Dray，Collision，Gravity,Dynamic
粒子渲染 Sprite渲染，网格体渲染，条带渲染

三、完整水珠流动 HLSL 源码

// 玻璃雨滴流动HLSL，附带变量注释
float2 uv = UV;
// 竖直向下偏移，模拟水珠往下滑落
uv.y += Time * FlowSpeed;
// 微小随机扰动，水珠不会规整平行流动
uv += RandomValue * Disturb;
float finalColor = Texture2DSample(RainTex,uv);
return finalColor;
